# Skill: Kod İnceleme

## Ne Zaman Kullanılır
Yazılan kod çalışmıyor, hata var, güvenlik açığı şüphesi, ya da "bu doğru mu?" sorusu.

## Kontrol Listesi
- [ ] Güvenlik açığı var mı? (SQL injection, XSS)
- [ ] Kullanılmayan kod var mı?
- [ ] Veritabanı sorguları doğru mu?
- [ ] Hata yönetimi var mı?
- [ ] Türkçe + Arapça desteği çalışıyor mu?
- [ ] Mobil / masaüstü uyum var mı?

## Çıktı Formatı
Sorun → Neden sorun → Nasıl düzeltilir → Öncelik (kritik / orta / düşük)
