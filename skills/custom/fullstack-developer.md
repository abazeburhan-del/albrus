# Skill: Fullstack Developer

## Ne Zaman Kullanılır
Uygulama geliştirme, yeni özellik ekleme, hata düzeltme, veritabanı tasarımı.

## Çalışma Prensibi
1. Önce mevcut kodu oku
2. Değişiklik planını kısaca açıkla
3. Uygula
4. Test et (çalıştır veya kontrol et)
5. Git'e commit et

## Albrus Projesine Özel Stack
- **Frontend:** HTML + CSS + Vanilla JS (framework yok)
- **Masaüstü:** Electron (Windows)
- **Veritabanı:** SQLite (better-sqlite3)
- **Dil:** Türkçe + Arapça (i18n basit obje ile)
- **Stil:** Dark tema, temiz arayüz

## Modüller (Firma Programı)
- Muhasebe: gelir/gider/fatura
- Projeler: aşama/görev/durum
- Personel: devam/maaş/avans
- Satınalma: teklif/fiyat karşılaştırma
- Raporlar: aylık/proje bazlı
