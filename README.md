# Albrus Company — Agent Mimarisi

Erbil merkezli elektrik, mekanik, inşaat ve dekorasyon firması **Albrus Company** için kişisel AI agent çalışma alanı.

## Dosya Yapısı

| Dosya | Açıklama |
|-------|----------|
| `CLAUDE.md` | Agent çalışma kuralları |
| `SOUL.md` | Ana kişilik ve prensipler |
| `SOUL-coder.md` | Geliştirici modu |
| `SOUL-strategist.md` | Stratejist modu |
| `SOUL-researcher.md` | Araştırmacı modu |
| `USER.md` | Kullanıcı profili |
| `MEMORY.md` | Kalıcı hafıza |
| `MISSION.md` | Misyon |
| `GOALS.md` | 3 aylık hedefler |
| `PROJECTS.md` | Aktif projeler |
| `PREFERENCES.md` | İletişim ve kod tercihleri |
| `LEARNED.md` | Öğrenilenler |
| `SERVICES.md` | Araçlar ve servisler |

## Klasörler

- `memory/` — Günlük çalışma notları (YYYY-MM-DD.md)
- `knowledge/` — Referans belgeler ve kontrol listeleri
- `skills/` — Agent becerileri
- `.claude/` — Claude Code ayarları

## Ana Hedef

Excel ve WhatsApp'tan çıkıp tek bir programda:
- Ön muhasebe (gelir/gider/fatura)
- Proje yönetimi (aşama/görev/personel)
- Satınalma ve teklif hazırlama
